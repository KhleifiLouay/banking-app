### Option 2: Use ngrok (Temporary, But Instant!)

If you want to test RIGHT NOW without deploying:

1. **Keep your backend running locally:**
   ```powershell
   cd backend
   npm start
   ```

2. **In another terminal, install ngrok:**
   ```powershell
   npm install -g ngrok
   ```

3. **Run ngrok:**
   ```powershell
   ngrok http 5000
   ```

4. **Copy the ngrok URL** (e.g., `https://abc123.ngrok.io`)

5. **Update frontend files** to use this URL

**But:** This only works while your computer is on.
