## ⚡ Quick Start (3 Steps)

1. **Deploy Backend** → Go to Render.com, connect GitHub, deploy
2. **Update API URL** → Replace `YOUR-BACKEND-URL` in frontend files with your Render URL
3. **Deploy Frontend** → Drag `frontend` folder to Netlify

**That's it!** 🎉

---

## 📝 Important Notes
